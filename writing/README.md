# WRITE IT — 考研英语二写作训练站

一个纯静态网页，面向考研英语二写作练习。无需安装依赖、无需后端，支持 GitHub Pages。

## 文件
- `index.html`：页面结构
- `styles.css`：简约响应式样式
- `app.js`：训练内容、交互、进度与草稿本地保存

## 本地预览
直接双击 `index.html` 即可在现代浏览器打开。

## GitHub Pages 部署
将这三个文件放在仓库的 `writing/` 文件夹中，提交到 `main` 分支。若仓库已启用 GitHub Pages，子站点地址为：

`https://<你的用户名>.github.io/<仓库名>/writing/`

## 功能
- 句子训练：连接词、语法纠错、图表主题句
- Part A 应用文：邀请邮件、道歉邮件、活动通知
- Part B 图表作文：柱状图、折线图、饼图
- 参考范文、提纲、表达库、自查清单、单词数统计
- 限时综合模拟与本地进度/草稿保存

## 真题与原创内容说明
网站按英语二常见写作任务形态设计：Part A 应用文与 Part B 图表类短文。练习情境、角色、图表和数字均为原创改编，不冒充某年真题原文。添加具体年份的真题题干或参考答案前，应以正式试卷核对并标注来源。

所有练习进度与草稿保存在当前浏览器的 `localStorage` 中。清除浏览器网站数据后，这些记录可能丢失；更换设备或浏览器不会自动同步。
